I rebuilt this place. Not because the old one was broken — it worked fine — but
because publishing to it had friction, and friction is how a personal site dies.

## Content lives in the repo now

Every post, project and study case is a markdown file under `src/content/`.
Adding something is a `git commit`. No CMS to log into, no draft stuck in a
dashboard I forgot the password to.

Bookmarks are the exception: they're one JSON file, so a sync script can rewrite
the whole thing without touching anything else.

## The look

Monospace, a dashed grid, one accent color. The reference was a set of technical
diagram sheets — dim rules, bright labels, everything on a strict baseline. Warm
paper (`#f3eadf`) for the ink, teal (`#34A893`) for the one thing you should
look at.
